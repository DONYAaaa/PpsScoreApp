# Учёт баллов ППС

Внутреннее веб-приложение для учёта индивидуальных показателей работы (ИП) профессорско-преподавательского состава по семестрам и формирования отчётности по кафедрам.

Преподаватели и сотрудники кафедр вносят выполненные виды работ за выбранный период, система автоматически начисляет баллы по утверждённой методике (с учётом лимитов по разделам и итоговому баллу) и формирует пакет отчётных документов: сводную таблицу в формате официальной формы (Excel) и пояснительные записки по каждому преподавателю (Word).

## Возможности

- **Справочники из коробки.** При первом запуске база наполняется списком кафедр и каталогом видов работ (5 разделов, фиксированные и вариативные баллы).
- **Ввод показателей.** Выбор преподавателя и периода (учебный год + семестр), добавление работ с автоматическим или выбираемым баллом, комментариями и прикреплением файлов-подтверждений.
- **Управление преподавателями.** Добавление и удаление сотрудников (удаление — с подтверждением и каскадной очисткой связанных записей и файлов).
- **Автоматический подсчёт.** Лимиты применяются на лету: не более 50 баллов на раздел, не более 100 итого, итоговый балл не опускается ниже 0.
- **Отчёты.** Выбор произвольного набора преподавателей, целой кафедры или всех сразу; предпросмотр на странице.
- **Экспорт одним архивом (.zip):**
  - сводный **Excel** в виде официальной формы — матрица «виды работ × преподаватели», подытоги по разделам, строка «Итого», подпись заведующего; альбомная ориентация, постраничная печать с повторяющейся шапкой, отдельный лист на каждую кафедру;
  - **Word** по каждому преподавателю — пояснения по пунктам с итогами и местом под подпись.

## Технологии

- .NET 10, Blazor Web App (рендеринг Interactive Server)
- Entity Framework Core 10 + Microsoft SQL Server
- ClosedXML — генерация Excel
- DocumentFormat.OpenXml — генерация Word
- QuestPDF — генерация PDF

## Требования

- .NET SDK **10.0** или новее
- Microsoft SQL Server: LocalDB, Express или полноценный экземпляр

## Быстрый старт

```bash
git clone https://github.com/DONYAaaa/PpsScoreApp.git
cd PpsScoreApp/src/PpsScoreApp

# указать строку подключения в appsettings.json (см. ниже)

dotnet restore
dotnet run
```

После запуска приложение доступно по адресу из консоли (по умолчанию `https://localhost:7242`). При первом старте автоматически создаётся база данных и наполняются справочники.

## Конфигурация

Параметры задаются в `src/PpsScoreApp/appsettings.json`.

### Строка подключения

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=(localdb)\\MSSQLLocalDB;Database=PpsScoreDb;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=True"
}
```

Пример для отдельного сервера с логином/паролем:

```
Server=ХОСТ,1433;Database=PpsScoreDb;User Id=ЛОГИН;Password=ПАРОЛЬ;TrustServerCertificate=True;MultipleActiveResultSets=true;Encrypt=True
```

`TrustServerCertificate=True` требуется, если на сервере самоподписанный сертификат (современный SqlClient по умолчанию шифрует соединение).

### Хранение вложений

```json
"FileStorage": {
  "Path": ""
}
```

Пустое значение — файлы сохраняются в `App_Data/uploads` рядом с приложением. Можно указать произвольный (в т.ч. сетевой) путь. В базе хранится только метаинформация о файлах; сами файлы лежат на диске.

## База данных

Схема создаётся при старте через `EnsureCreated`, после чего справочники кафедр и видов работ наполняются один раз (при пустых таблицах). Пользовательские данные при перезапусках не затрагиваются. Учётной записи БД нужны права на создание базы; либо база создаётся администратором заранее — тогда приложение только наполнит её.

### Переход на миграции

Для версионирования схемы при дальнейшем развитии:

1. В `Data/DbInitializer.cs` заменить `EnsureCreatedAsync()` на `MigrateAsync()`.
2. Создать и применить миграцию:

   ```bash
   dotnet tool install --global dotnet-ef
   dotnet ef migrations add Initial
   dotnet ef database update
   ```

Наполнение справочников выполняется в `DbInitializer` и остаётся рабочим.

## Методика начисления

Правила лимитов реализованы в `Services/ScoringRules.cs`:

| Параметр | Значение |
|---|---|
| Максимум на раздел | 50 |
| Максимум итого | 100 |
| Нижняя граница итога | 0 |

Итоговый балл = сумма разделов (каждый ограничен 50), затем ограничение сверху 100 и снизу 0.

Каталог видов работ и баллов вынесен в `Data/SeedData.WorkTypes.cs`, список кафедр — в `Data/SeedData.Departments.cs`; формулировки, баллы и варианты правятся там.

## Сборка и развёртывание

Публикация:

```bash
dotnet publish src/PpsScoreApp -c Release -o ./publish
```

Приложение размещается под Kestrel/IIS во внутренней сети. Требования к окружению:

- доступ к экземпляру SQL Server;
- права на запись в каталог вложений (`App_Data/uploads` или заданный в конфигурации);
- каталог вложений резервируется вместе с базой данных — ссылки на файлы хранятся в БД, а содержимое на диске.

## Примечания

- Приложение работает без аутентификации и рассчитано на размещение во внутренней сети.
- Для PDF используется шрифт Times New Roman; на серверах без него возможна подстановка шрифта.
- QuestPDF подключён по лицензии Community; условия использования задаются в `Program.cs`.
